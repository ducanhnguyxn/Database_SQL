In the directory that is unzipped you will find each file is numbered from 00 to 15. As part of the filename shows how many marks can be achieved as part of that task.

You are required to complete the tasks in order and follow the descriptions for each task. Please read carefully the description carefully and ask questions at Practical Sessions. Then, edit these files, write your code, SAVE YOUR WORK in those files so you can run them again if you need to on one drive.  

Run the test cases to confirm you are on the right track. The test cases provided will not test everything for you, so you need to read and follow the instructions for each of the tasks.

You are required to work while connected to the University of Hertfordshire database and you MUST make use of your UH Oracle Account to complete this task. If remotely working you will need to be connected via Ivanti VPN to be able to run queries on the database.

You will be marked at the end date for the assessment using the objects and data that you have created within your database. When the end date and time is up. If you try to change or recreate any objects after the assessment time has finished this will be classified as trying to cheat.
